AutoScrapeClient

class AutoScrapeClient(context: Context) : Closeable

Automated e-receipt scrape client: schedules a periodic background scrape of the linked Gmail IMAP accounts (the initial provider scope, see isAutoScrapeAccount) through the existing ImapClient.remoteMessages path — the same backend job the manual remote scrape creates — and delivers each account's JobResults to the callbacks supplied to begin. Receipts themselves are parsed server-side and posted to the configured client endpoint, exactly like a manual remote scrape; the callbacks carry the job handle, not scan results.

Mirrors com.microblink.linking.AccountLinkingClient: the host owns the instance and passes its result/error callbacks straight into begin. The callbacks are held only by a collector coroutine in this client's own scope — nothing is registered statically — and the worker reaches them by emitting into a stateless per-process event stream (events) that the collector consumes. Off until begin is called, and the arm state lives in memory only, so hosts re-create the client and call begin at launch (e.g. in Application.onCreate) to re-arm it before any scheduled run fires.

The background schedule itself follows the signed-in state (AutoScrapeScheduler): while armed, the periodic work exists only when an in-scope account is linked — it starts when such an account signs in and is cancelled when the last one signs out. All scheduling funnels through the one unique-work name, so there is never more than one worker ticking regardless of how many times (or from how many clients) auto-scrape is armed.

var intervalHours: Int

The cadence, in hours, of the automated scrape — the public override for the default DEFAULT_INTERVAL_HOURS (24h) refresh. The only limitation is the MIN_INTERVAL_HOURS (12h) floor: values below it (including zero and negatives) fall back to 12, and anything at or above it is used as-is with no upper cap. Changing it while the client is armed reschedules the periodic work so the new cadence takes effect immediately (mirrors iOS's autoScrapeInterval setter); otherwise the value applies the next time the client is armed.
